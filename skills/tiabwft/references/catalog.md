# Starter catalog: goal → better way

Hints only. Check each one live (registry, plugin search, web) before you recommend it, and drop anything that no longer exists. Edit this file freely to add your own favourites.

| Goal | AI / where it runs | Connectors worth checking | Skills / plugins worth checking |
|---|---|---|---|
| Build an AI agent | Claude Agent SDK for custom agents in code; Claude Managed Agents for a hosted sandbox; scheduled cloud routines for agents that run on a timer | the systems the agent acts on (CRM, email, docs, database) | `claude-api` skill, `small-business:build-agent`, `small-business:build-connector` |
| Website / web app | Lovable or Wix for no-code or low-code; Claude Code + a framework for custom work | Supabase (database/auth), Stripe (payments), Shopify (store) | `web-artifacts-builder`, `wix:*`, design and accessibility skills |
| Sales / CRM / leads | Claude with CRM tools in the loop | HubSpot, Apollo, Clay, Gmail, Google Calendar | `small-business:lead-finder`, `crm-autopilot`, `speed-to-lead`, `outreach-composer` |
| Content / social media | Claude for drafting; schedulers to publish | Typefully, Metricool, Publora, Canva | `marketing:*`, `linkedin-skills:*`, `small-business:social-content-engine` |
| Notes / knowledge / memory | a local vault Claude can read and write | Obsidian (vault on disk), Google Drive, Notion | `llm-wiki:*` for a self-maintaining wiki, Claude memory |
| Data / reports | Claude + a database or spreadsheet | Supabase, Google Sheets, analytics tools (Amplitude, Similarweb) | `xlsx`, `dataviz`, `small-business:report-builder` |
| Project / team work | Claude with the tracker connected | Linear, Asana, ClickUp, monday.com, Atlassian | `product-management:*`, `engineering:standup` |
| Repeating tasks | scheduled tasks / `/loop` / cloud routines instead of doing them by hand | whatever the task touches | `schedule`, `loop` |
| Faster communication | Slack or email connected so Claude drafts replies in context | Gmail, Slack, Fireflies (meeting notes) | `small-business:inbox-manager` |
